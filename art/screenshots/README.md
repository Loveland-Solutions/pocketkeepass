# Store screenshots

Phone screenshots for Google Play, 1080 × 1920 (9:16, which Play requires), taken on the API 37 emulator with
`art/demo/Demo.kdbx` (renamed `Personal.kdbx` on the device).

`FLAG_SECURE` blanks every screenshot of the app, so they were taken from a local debug build with the flag
commented out in `MainActivity`, never committed. The emulator ran at `wm size 1080x1920`, `wm density 420`,
with System UI demo mode for a clean status bar.
